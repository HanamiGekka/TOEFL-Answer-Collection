# Synthetic package directory example

`Mock.99.Z.1/` is an invented package name matching the application's existing `Mock.NN.L.N` directory scanner. It is not an exam date or a real TOEFL package. The scanner reads only immediate package directory names; it does not import these placeholder files or display question content.

The three section directories represent the Reading, Listening, and Writing choices of a new dynamic schema v6 Session. The user creates answer Items inside the app. The example contains no questions, audio, transcripts, answers, answer keys, or user data. Legacy Speaking is intentionally absent.

For a local scanner demonstration, select this `samples/` directory as SOURCE_ROOT in a disposable APP_ROOT. Do not mix this example with real study materials.
